# mcTTT
These codes are related to "Market credibility of time to transition to a low-carbon economy" available at https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6135666

This repository contains the R code implementation for the paper: "Market credibility of time to transition to a low-carbon economy" Lorenzo Mercuri, Andrea Perchiazzo, Edit Rroji, and Ilaria Stefani (2026).

Overview

The provided scripts allow for the calibration of two innovative models designed to extract transition expectations from financial markets: RDCM: Regulatory Deadline-Constrained Model (Vasicek extension with terminal conditions). SRDCM: Switching Regulatory Deadline-Constrained Model (regime-switching framework).

Data & Calibration The models are estimated using market data from German sovereign twin bonds to estimate the perceived timing of the transition to a low-carbon economy.

Reference For theoretical details and empirical results, please refer to the full paper on SSRN: https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6135666
